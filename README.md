# Weekly Budget — Web

Desktop web version of Weekly Budget, live at https://budgeting-app-dfbde.web.app (Google sign-in + Firestore sync).

- Edit `src/app.jsx`, then run `node build.js` to compile it to `public/app.js` (no runtime Babel).
- Deploy with `firebase deploy`. See `FIREBASE_SETUP.md`.

The Android app lives in the `weekly-budget-android` repo and is compiled with this repo's `build.js`.
